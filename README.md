# do. – Task Management Web App

A beautiful and fully functional task manager built with **pure HTML, CSS, and JavaScript**.

![Demo](https://via.placeholder.com/800x400?text=do.+Task+Manager+Screenshot)

## ✨ Features

- Add, edit, and delete tasks
- Drag & Drop reordering
- Due dates with calendar
- Priority levels (High, Medium, Low)
- Categories (Work, Personal, Study, Health, Others)
- Real-time Search & Filter
- Progress tracking with animated bar
- Dark & Light Mode
- Data saved automatically (`localStorage`)
- Fully responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3 (Custom Properties + Modern Design)
- Vanilla JavaScript (No frameworks)
